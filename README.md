# Bappy Portfolio

Premium responsive portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — theme toggle, typing effect, scroll reveal, progress bar and mobile menu
- `assets/` — add your personal images and video here

## Add your media
Place these files in the `assets` folder:
- `profile.png`
- `work-experience.jpg`
- `video-cv.mp4`

Optional: add your PDF CV as `assets/Fazlul-Karim-Bappy-CV.pdf` (the current page does not yet include a download button).

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Before publishing
Check that your job title, work dates, experience description, phone number, email and location are accurate. The portfolio currently uses the details supplied in the conversation.
